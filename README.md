# Разведчик — autonomous OSINT agent

Разведчик — исследовательский агент для поиска и корреляции сведений из открытых и легитимно доступных источников. После запуска он сам формирует новые запросы, использует найденные идентификаторы как точки перехода и сохраняет доказательства с привязкой к источникам.

## Возможности

- режимы: FIO, username, nickname, phone, e-mail и combined;
- автономные волны поиска без ручного подтверждения каждого шага;
- web-поиск;
- прямые публичные источники: GitHub, GitLab и Wikidata;
- опциональный Sherlock как дополнительный мост для массовой проверки username, а не как база данных;
- нормализация идентификаторов и автоматические pivots между найденными признаками;
- для FIO поддерживаются дополнительные контекстные признаки — год или полная дата рождения;
- консервативная корреляция: совпадение не считается подтверждённой личностью только по одному слабому признаку;
- отдельные кандидаты для сведений, которые нельзя безопасно связать между собой;
- сущности и связи с доказательствами, URL и источниками;
- JSON и Markdown-досье с отдельным описанием покрытия расследования;
- опциональный OpenAI-слой для планирования следующих поисковых ходов;
- запуск в GitHub Actions без локального ПК.

## Архитектура источников

Разведчик не пытается хранить собственную гигантскую базу данных. Он обращается к источникам во время расследования и сохраняет только полученные доказательства и связи.

Прямые коллекторы являются самостоятельными источниками: GitHub public search, GitLab public user search и Wikidata public knowledge base. Web search является поисковым агрегатором. Sherlock остаётся опциональным мостом для username-проверок: он сам обращается к публичным сайтам, а не предоставляет собственную базу людей.

Такой подход позволяет постепенно добавлять новые независимые коллекторы без привязки всего агента к SpiderFoot или Sherlock.

## Статус подтверждения

`found mention` означает, что источник действительно содержит найденное упоминание. `possible match` означает возможное совпадение, но не доказанную принадлежность сведений одному человеку. `confirmed by source` используется только когда один стабильный идентификатор независимо подтверждён несколькими источниками и доменами.

## Ограничения

Агент работает только с открытыми либо легитимно доступными данными. Он не обходит авторизацию, paywall или CAPTCHA, не получает доступ к закрытым базам, не использует украденные базы и не пытается получать непубличные персональные данные.

Photo mode пока не активирует биометрическую идентификацию: для него требуется отдельный легитимный визуальный источник.

GetContact не подключён как внутренний источник: публичного официального внешнего API для такого использования не настроено, поэтому агент не пытается обходить приложение или его защиту.

## Запуск локально

```bash
python -m razvedchik --mode fio --query "Иванов Иван Иванович 1981"
```

Sherlock подключается автоматически, если команда `sherlock` установлена и доступна в PATH. В GitHub Actions он устанавливается отдельным шагом рабочего процесса расследования.

## Запуск в GitHub Actions

Откройте `Actions → Разведчик → Run workflow` и задайте режим, исходный запрос, количество волн и количество результатов на запрос.

Для AI-планировщика добавьте секрет репозитория `OPENAI_API_KEY`. Без него агент продолжает работу с детерминированным планировщиком.

Результат сохраняется как артефакт `razvedchik-dossier` в форматах JSON и Markdown. В отчёте отдельно указываются прямые источники, дополнительные мосты, фактически наблюдавшиеся источники и ограничения покрытия.
