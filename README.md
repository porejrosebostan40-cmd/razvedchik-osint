# Разведчик — autonomous OSINT agent

Разведчик — исследовательский агент для поиска и корреляции сведений из открытых и легитимно доступных источников. После запуска он сам формирует новые запросы, использует найденные идентификаторы как точки перехода и сохраняет доказательства с привязкой к источникам.

## Возможности

- автоматический мониторинг публичных источников;
- ротация региональных запросов;
- фильтрация поисковых страниц и нерелевантных результатов;
- deterministic evidence graph с source-family, temporal-order и contradiction checks;
- компактный AI-контекст с ограничением доказательствами;
- калибровка прогнозов только по разрешённой истории;
- безопасный fallback UNKNOWN при недостатке доказательств или недоступности AI;
- сохранение состояния с ограничением размера.
