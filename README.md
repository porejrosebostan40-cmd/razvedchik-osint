# Разведчик — autonomous OSINT agent

Разведчик — исследовательский агент для поиска и корреляции сведений из открытых и легитимно доступных источников.

## Возможности v0.1

- режимы: FIO, username, nickname, phone, e-mail и combined;
- автономные волны поиска без ручного подтверждения каждого шага;
- нормализация идентификаторов и автоматический переход к найденным связям;
- разделение кандидатов: совпадение не считается доказанным только по одному признаку;
- фиксация источника, URL, типа доказательства и уровня уверенности;
- JSON и Markdown-досье;
- опциональный OpenAI-слой для планирования и корреляции;
- запуск в GitHub Actions без локального ПК.

## Ограничения

Агент работает только с открытыми либо легитимно доступными данными. Он не обходит авторизацию, paywall, CAPTCHA, закрытые базы, не использует украденные базы и не пытается получать непубличные персональные данные.

## Запуск

Локально:

```bash
python -m razvedchik --mode fio --query "Иванов Иван Иванович"
```

В GitHub Actions: `Actions → Разведчик → Run workflow`.

Для AI-планировщика добавьте секрет репозитория `OPENAI_API_KEY`. Без него агент использует детерминированный планировщик.
